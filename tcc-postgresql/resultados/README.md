# Resultados

- `brutos/` — saída direta das execuções, sem tratamento. Arquivos volumosos
  não são versionados; ver `.gitignore`.
- `processados/` — conjuntos consolidados, tabelas e figuras que aparecem no artigo.

Cada execução registra, junto aos dados, a arquitetura, o eixo, o nível de
concorrência, a duração, o digest das imagens utilizadas e a telemetria de
host correspondente.
