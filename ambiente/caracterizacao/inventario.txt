INVENTÁRIO DO AMBIENTE DE MEDIÇÃO
=================================


Estado registrado: o padrão da máquina, fora de janela de coleta. Durante as
coletas aplicam-se as ADR-015 a ADR-019 (docs/decisoes-arquiteturais.md).
Os comandos usados estão na seção 10. Números de série e UUIDs foram omitidos.


1. SISTEMA
----------
Sistema operacional ......... Ubuntu 26.04.1 LTS, instalação nativa no P510
Kernel ...................... 7.0.0-38-generic
Parâmetros do kernel ........ quiet splash crashkernel=... (padrão do Ubuntu;
                              reserva 512 MiB para o kernel de despejo nesta
                              faixa de memória). Nenhum parâmetro de
                              desempenho alterado.


2. PLACA-MÃE E FIRMWARE
-----------------------
Placa-mãe ................... ASUS PRIME B650EM-A, Rev 1.xx
BIOS/UEFI ................... American Megatrends, versão 0221, de 07/04/2025


3. PROCESSADOR
--------------
Modelo ...................... AMD Ryzen 7 9700X (Zen 5, família 26, modelo 68)
Núcleos / threads ........... 8 / 16, SMT ativo
Topologia SMT ............... núcleo físico N = processadores lógicos N e N+8
                              (núcleo 0 = CPUs 0 e 8 ... núcleo 7 = CPUs 7 e 15)
Frequência .................. 605 MHz (mínima) a 5582 MHz (máxima com boost)
Boost ....................... habilitado
Microcódigo ................. 0xb404023
Caches ...................... L1d 48 KiB e L1i 32 KiB por núcleo
                              L2 1 MiB por núcleo
                              L3 32 MiB, um único bloco compartilhado pelos
                              8 núcleos
NUMA ........................ 1 nó
Extensões relevantes ........ AVX2, AVX-512 (inclui VNNI e BF16)
Driver de frequência ........ amd-pstate-epp, modo ativo, prefcore habilitado
Perfil de energia padrão .... power-profiles-daemon em "balanced": governador
                              powersave, EPP balance_performance
Durante as coletas .......... perfil "performance": governador e EPP em
                              performance nos 16 processadores (ADR-015)
Estados ociosos (C-states) .. POLL; C1 (saída em 1 µs); C2 (18 µs);
                              C3 (350 µs). Todos habilitados.
Mitigações de CPU ........... padrão do kernel. Com mitigação ativa: Spectre v1,
                              Spectre v2 (IBRS automático), Speculative Store
                              Bypass, SRSO e VMSCAPE. Demais: não afetado.

Swap padrão ................. arquivo /swap.img de 8 GB, ativado pelo fstab;

Transparent Huge Pages ...... enabled = madvise; defrag = madvise
Huge pages estáticas ........ 0
vm.swappiness ............... 60
vm.dirty_ratio .............. 20
vm.dirty_background_ratio ... 10
vm.dirty_expire_centisecs ... 3000
vm.overcommit_memory ........ 0
kernel.numa_balancing ....... 0


5. ARMAZENAMENTO
----------------

5.1 Dispositivo de medição: nvme0, Crucial P510

Modelo ...................... Crucial P510 1 TB (CT1000P510SSD5), sem DRAM
Firmware .................... K1CR5102
Interface ................... PCIe 5.0 x4, link negociado em 32 GT/s x4
                              (endereço PCI 02:00.0)
Capacidade .................. 1.000.204.886.016 bytes
Formato de setor ............ 512 B, único formato oferecido pelo firmware
Cache de escrita volátil .... habilitado (kernel: write back)
Transferência máxima ........ 256 KiB pelo controlador (MDTS = 6); o kernel
                              divide requisições em até 128 KiB
                              (max_sectors_kb)
Gerência de energia (APST) .. habilitada. O kernel aceita estados com latência
                              de até 100 ms (nvme_core.default_ps_max_latency_us
                              = 100000), o que inclui PS3 e PS4
Estados de energia .......... PS0 7,5 W | PS1 2,4 W | PS2 1,5 W (operacionais)
                              PS3 0,03 W, entrada 5 ms, saída 2,5 ms
                              PS4 0,003 W, entrada 10 ms, saída 40 ms
Dica de carga (feature 0x02)  2, "escrita sequencial intensa". Valor encontrado
                              no dispositivo, não alterado por este trabalho.
PCIe ASPM ................... L1 habilitado no link; política do kernel
                              "default" (definida pelo firmware)
Temperaturas-limite ......... aviso 83 °C; crítica 85 °C
Sensor de temperatura ....... /sys/class/nvme/nvme0/hwmon*/temp1_input,
                              legível sem root
Escalonador de I/O .......... none
Fila do kernel .............. nr_requests 1023; read_ahead 128 KiB
SMART (25/10/2026, 20:05) ... 0% de desgaste, 46 h ligado, 2,99 TB gravados
                              (inclui os testes de caracterização de 24 e
                              25/10), 0 erros de mídia, 0 desligamentos
                              inseguros, 37 °C em repouso

5.2 Partições e sistema de arquivos

nvme0n1p1 ................... 1 GB, vfat, /boot/efi
nvme0n1p2 ................... 930,5 GB, ext4, /
Opções de montagem .......... rw,relatime. Sem discard. Journal em modo ordered
                              e commit a cada 5 s (padrões do ext4)
Bloco / inode ............... 4096 B / 256 B
Recursos do ext4 ............ has_journal, extent, 64bit, flex_bg,
                              metadata_csum, orphan_file, dir_index, huge_file,
                              large_file, sparse_super
Criado em ................... 19/10/2026
Ocupação .................... 20 GiB de 915 GiB (3%); 849 GiB disponíveis
Reserva para root ........... 5% (46,5 GiB)
Descarte (TRIM) ............. padrão: fstrim.timer semanal. Durante as coletas:
                              sync seguido de fstrim manual (ADR-017)

4% de desgaste em 24/10/2026.

10. COMANDOS DE COLETA
----------------------
cat /etc/os-release; uname -r; cat /proc/cmdline
cat /sys/class/dmi/id/{board_vendor,board_name,board_version}
cat /sys/class/dmi/id/{bios_vendor,bios_version,bios_date}
lscpu; lscpu -e; grep -m1 microcode /proc/cpuinfo
cat /sys/devices/system/cpu/amd_pstate/{status,prefcore}
cat /sys/devices/system/cpu/cpu0/cpufreq/{scaling_driver,scaling_governor}
cat /sys/devices/system/cpu/cpu0/cpufreq/energy_performance_preference
cat /sys/devices/system/cpu/cpu0/cpuidle/state*/{name,latency,disable}
powerprofilesctl get
sudo dmidecode -t memory
free -h; swapon --show
sysctl vm.swappiness vm.dirty_ratio vm.dirty_background_ratio \
       vm.dirty_expire_centisecs vm.overcommit_memory vm.nr_hugepages \
       kernel.numa_balancing
cat /sys/kernel/mm/transparent_hugepage/{enabled,defrag}
sudo nvme list
sudo nvme id-ctrl /dev/nvme0
sudo nvme id-ns /dev/nvme0n1
sudo nvme get-feature /dev/nvme0 -f 0x0c -H     # APST
sudo nvme get-feature /dev/nvme0 -f 0x02 -H     # gerência de energia
sudo nvme get-feature /dev/nvme0 -f 0x06 -H     # cache de escrita volátil
sudo nvme smart-log /dev/nvme0
sudo lspci -vv -s 02:00.0                       # link PCIe e ASPM
cat /sys/module/nvme_core/parameters/default_ps_max_latency_us
cat /sys/module/pcie_aspm/parameters/policy
cat /sys/block/nvme0n1/queue/{scheduler,nr_requests,read_ahead_kb}
cat /sys/block/nvme0n1/queue/{write_cache,max_sectors_kb}
findmnt /; sudo tune2fs -l /dev/nvme0n1p2; df -h /
docker version; docker compose version; docker info
nvidia-smi --query-gpu=name,driver_version,pstate,power.draw --format=csv
systemctl list-timers --all
